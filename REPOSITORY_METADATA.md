## v3.0 beta highlights

- Browser File Manager + WebDAV from one Android server
- Automatic Windows Drive setup served directly by the APK
- WinFsp/rclone large-file mount path for Windows Explorer
- LAN auto-discovery with persistent PocketNAS device ID
- Auto-remount after Windows sign-in or phone IP changes
- Fixed Android All files access navigation with OEM fallback
